### Hosting your own site
Probally important that this is mainly here for my friend who is learning frontend development.

I want to streamline this process within the site itself, but for now simple create a branch of this repo.
In the branch do the following
- In the root folder create a folder with your sites name
- Add atleast a index.html file
    - Subfolders are allowed, but keep to a minimum as I have to manually review each commit.
- Any assets (css, js, images) must go in my assets folder
    - Create a subfolder for your site which will contain it all
- When ready create a pull request and I will review it.

Any addition must meet these requirments
- Frontend only
- No profanity / explicit material
- Must be small enough to review manually
- JS must only interact with your HTML pages, no cookies etc
- Who the website is by must be clearly visibly on intial load.
- does not modify any of my code
Any pull requests that do not meet these requirments will be automaticly denied.
